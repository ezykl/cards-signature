Step-by-step setup

Add your signature to your inbox

  1. Click Copy for Gmail / Outlook in Signature Studio.
  2. Open Gmail and click the Settings gear (⚙) → See all settings.
  3. Scroll down to the Signature section and click + Create new.
  4. Click inside the signature text box and press Ctrl + V (or Cmd + V on Mac) to paste.
  5. Scroll to the bottom of the page and click Save Changes.
  1. Click Copy for Gmail / Outlook in Signature Studio.
  2. In Outlook (Web or Desktop), open Settings → Mail → Compose and reply (or File → Options → Mail → Signatures).
  3. Create a new signature, click inside the editor box, and press Ctrl + V (or Cmd + V).
  4. Set it as default for new messages and replies, then click Save.
  1. Click Copy for Gmail / Outlook in Signature Studio.
  2. Open Apple Mail and go to Mail → Settings → Signatures.
  3. Create a signature with the + button and uncheck "Always match my default message font" so your layout and colors are preserved.
  4. Paste with Cmd + V (note: the preview box may hide images until you open a new compose window).
  1. Google Drive Logos & CVs: Right-click your file in Google Drive → Share → set General Access to "Anyone with the link". Paste the link directly into Signature Studio—we automatically convert it into a direct image or document link!
  2. GitHub Assets: Paste any public GitHub file link (`github.com/.../blob/...`) or your GitHub profile URL—we automatically convert it to the raw asset CDN.
  3. Zero-Upload Option: Click Initials Badge or GitHub Avatar beneath the Logo field for an instant hosted image without uploading any file.
