# Cards Signature

A collection of responsive, designer HTML email signature cards and assets.

## Cards Included
- **Ezekiel P. Villadolid Signature Card** (`email-signature.html`)
  - Deep-blue vortex card background
  - Coral-red (`#ff5252`) icons for Phone, Email, and Location
  - Social CTA buttons (GitHub Profile & Connect on LinkedIn)
  - Full-width Download CV / Resume CTA
  - Fully fluid and responsive for desktop and mobile email clients

## How to Use
1. Open `email-signature.html` in any web browser.
2. Select the rendered signature card and copy it (`Ctrl + C` / `Cmd + C`).
3. Paste it directly into your email client's signature settings (Gmail, Outlook, Apple Mail, Thunderbird, etc.).
